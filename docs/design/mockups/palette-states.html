Command palette, empty states, errors, toasts and loading

Covers UX-04/05/06 and PERF-02 (ux-design §18, §21, §4.11, §4.12, §5.4). Every empty state has a next action, every error says what happened, where, and what to do next, and every message offers Show Git output.

1. Command palette (Mod+K)

Opens with the cursor in the input. Suggested actions come from state. An unavailable action is dimmed and shows its reason where the key hint would be; choosing it shows the reason as a toast.

2. Palette variants

Matched characters are weight 600, not colour. Choosing a repo opens its actions; Backspace on an empty input goes back.

3. Loading from cache (PERF-02), offline, toasts

First paint shows the last known state at normal contrast with the history mark until live data arrives ("Updating 6 repos…"). A newly found repo without cache shows skeleton bars and "Reading…". Toasts stack bottom right, newest at the bottom, at most 3.

5. Error messages (§21.3)

What happened, where, what next. The first action is the fix; Show Git output is always offered. Conflicts and preflight changes are pauses, not failures. Proposed error codes are shown on the right for reference only.

Pull stopped: app-front has local changes that the pull would overwrite. Stash them or commit first.

git.pull.dirty_worktree

Pull stopped: app-api's branch and origin have both moved, so it can't fast-forward. Run Update from branch to merge origin in.

git.pull.not_fast_forward

Push rejected: origin/TK-2636-taosif-Onboarding in app-front has commits you don't have. Pull first, then push again.

git.push.non_fast_forward

Force push refused: someone pushed to TK-2636-taosif-Onboarding in app-api since your last fetch. Fetch, look at their commits, then try again.

git.push.lease_rejected

Fetch failed: origin refused the credentials for app-report-api. Set up your Git login, then retry.

git.auth_failed

Fetch timed out: app-signalr-api got no answer from origin for 120 s. Check your network or VPN, then retry.

git.timeout.network

Commit stopped: another Git program is using app-api right now (index.lock exists). Close it in VS Code or the terminal, then retry.

git.index_lock

Commit stopped: app-front's pre-commit hook failed. Your changes are still there. Fix what the hook reports, then commit again.

git.hook_rejected

Update from main paused: app-api has 3 files that need you to choose what to keep. Resolve them, then Resume.

git.merge.conflict

6. Banners (§4.11)

1 repo needs review before GitHeddle runs Git in it.
Your GitHub sign-in has expired. Pull request status and creation are paused.

At most two banners show at once; the rest collapse into the "1 of 3 ▾" switcher. The first two are shown here as a pair, the last two as the next items.

7. Toasts (§4.12)

Durations: success 4 s, info and failure 6 s, with an action 8 s, with Undo 10 s (R30). They pause while hovered or focused.
